# Agent Instructions

This repository is designed to be worked on by humans and AI agents from multiple providers and toolchains.

Before making changes:

1. Read this `AGENTS.md`.
2. When entering a child directory, check whether that directory contains its own `AGENTS.md`.
3. If a nested `AGENTS.md` exists, read it before modifying files in that directory.
4. Repeat this process as you move deeper into the repository.

Nested `AGENTS.md` files provide more specific context for the area they are located in.

If instructions appear to conflict or are unclear, surface the conflict instead of guessing.

Keep agent instructions provider-neutral wherever practical.
