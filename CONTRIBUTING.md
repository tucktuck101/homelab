# Contributing

ClankerOps Homelab is primarily a personal engineering and portfolio project.

External contributions may be accepted by prior arrangement.

## Contributing to the Project

If you are interested in contributing, reviewing part of the implementation, or discussing a potential change, contact:

`hello@clankerops.nz`

Please include enough context for me to understand:

* who you are
* what you are interested in contributing to or reviewing
* why you would like access or involvement
* any relevant GitHub profile, organisation, or professional context

Do not submit substantial pull requests without prior discussion, as they may be closed without review.

## Access to Live Implementations

Temporary access to selected live ClankerOps services or private infrastructure may be provided for legitimate review, collaboration, demonstration, or evaluation purposes.

Access is granted only after the requester has been individually verified and the intended scope has been agreed.

Any access provided may be:

* limited to specific services or capabilities
* read-only where appropriate
* time-limited
* monitored or audited
* revoked at any time

Public access to the source code or documentation does not imply authorization to access associated private infrastructure.

## Security Issues

Security vulnerabilities should not be reported through normal contribution channels or public issues.

See [`SECURITY.md`](SECURITY.md) for the appropriate disclosure process.
